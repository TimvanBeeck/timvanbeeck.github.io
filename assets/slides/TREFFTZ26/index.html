Motivation

Motivation

Least squares finite element methods (LSFEM) minimize the PDE residual Bochev, Gunzburger (2009)

\[ \A u = f \ \text{in } \Omega, \quad \B u = 0 \ \text{on } \partial \Omega \qquad \Longrightarrow \qquad \begin{aligned} u &= \operatorname*{argmin}_{v \in X} \J(v), \\[0.2em] \J(v) &= \Vert f - \A v \Vert^2_{L^2(\Omega)} + \Vert \B v \Vert^2_{L^2(\partial \Omega)} \end{aligned} \]
Advantages
  • naturally symmetric positive definite system matrix
  • no inf-sup condition, no compatibility conditions, ...
  • built-in adaptive error estimators
Disadvantages
  • second order problem → fourth order least square system, need $H^2$-conforming space
  • condition number of the system matrix scales like $\mathcal{O}(h^{-4})$

Can we Trefftzify?

Motivation

Three paradigms of LS FEM

“the first key to defining a practical LSFEM is to recast the given PDE system into first-order system form”

1 Easily assembled

matrices and right-hand sides of the discrete problem are “easily” computable

2 Standard spaces

no finite element spaces harder to work with than those of the usual Galerkin and mixed-Galerkin methods for the same problem

3 Conditioning

a condition number comparable to those of the same Galerkin and mixed-Galerkin methods

  • First order system least squares (FOSLS): introduce auxiliary $\bm{\sigma}$ and solve mixed problem
    • requires less conformity, condition number down to $\mathcal{O}(h^{-2})$
    • increases degrees of freedom

Motivation

Trefftz Least Squares Methods

  • Idea is not new: plane wave Trefftz LS methods for Helmholtz Stojek (1998) and Monk, Wang (1999)
  • Embedded Trefftz DG (ETDG) method constructs the Trefftz space elementwise Lehrenfeld, Stocker (2023)
    • works for more general problems
  • Goal: apply the ETDG to LS
    • DG method, work directly with the second order formulation
    • Conditioning of $\mathcal{O}(h^{-4})$ unavoidable, but much cheaper in terms of dofs
    • Well suited for adaptivity with coarsening → polytopal mesh elements Lehrenfeld, Stocker, Zienecker (2024)

The method

Embedded Trefftz DG — the idea

  • Goal: want to realize \[ \IT = \{ v \in \Vh : \Pi_K \A v = 0 \ \forall K \in \Th \} \]
  • Idea: express Trefftz basis $\{ \psi_j \}_{j=1}^M$ in terms of DG basis $\{ \varphi_i \}_{i=1}^N$ of $\Vh = \IP^k(\Th)$ via embedding $\ T \in \mathbb{R}^{N \times M}$ \[ \text{Solve } T^\top A T = T^{\top} f \]
  • Elementwise construction: compute with SVD \[ T\vert_K = \ker (W_K), \qquad (W_K)_{ij} = (\A \varphi_j, \A \varphi_i)_K \]
  • Inhomogeneous problems $\A u = f$: compute particular solution with a pseudo-inverse, $\bm{u}_f\vert_K = W_K^\dagger \bm{w}_K$, $(w_K)_i = (f, \A \varphi_i)_K$, then $u_h = T \bm{u}_T + \bm{u}_f$
  • $\kappa(\Am^{\text{ETDG}}) \le \kappa(\Am^{\text{DG}})$

Lehrenfeld, Stocker, Embedded Trefftz discontinuous Galerkin methods, IJNME, 2023.

Lederer, Lehrenfeld, Stocker, Voulis, Embedded Trefftz DG framework for the analysis of discretizations with local-global decompositions, arXiv, 2024.

The method

Application to Least Squares FEM

  • DG least squares (DGLS): find $u_h \in V_h \coloneqq \IP^k(\Th)$ such that \[ u_h \in \arg\min_{v_h \in \Vh} \J_h(v_h), \qquad \J_h(v_h) = \Vert f - \A v_h \Vert^2_{L^2(\Th)} + \vert v_h \vert^2_{j,h} \]
  • Conformity is replaced by a jump stabilization: for $\alpha_d, \alpha_n, \alpha_b > 0$ \[ j_h(u,v) \coloneqq \alpha_d \bigl( \dgjump{u}, \dgjump{v} \bigr)_{\Fhi} + \alpha_n \bigl( \dgjump{\nabla u \cdot \bm{n}}, \dgjump{\nabla v \cdot \bm{n}} \bigr)_{\Fhi} + \alpha_b \bigl( \B u, \B v \bigr)_{\Fhb}, \qquad \vert v \vert^2_{j,h} \coloneqq j_h(v,v) \]
Embedded Trefftz DG least squares (ETLS)
We define the projected functional \[ \widehat{\J}_h(v_h) \coloneqq \Vert \Pi(f - \A v_h) \Vert^2_{L^2(\Th)} + \vert v_h \vert^2_{j,h}. \] The ETLS method then solves the constrained minimization problem \[ \min_{v_h \in \Vh} \widehat{\J}_h(v_h) \qquad \text{subject to} \quad \Pi (\A v_h - f) = 0 \]

The method

An equivalent mixed formulation

  • A1: the constraint set $\Vh^f$ is nonempty
  • A2: $j_h(\cdot,\cdot)$ is Hermitian positive semidefinite on $\Vh$ and $\vert \cdot \vert_{j,h}$ is a norm on $\IT \coloneqq \bigoplus_{K \in \Th} \{ v_h \in \IP^p(K) : \Pi_K (\A v_h) = 0 \}$
Theorem (Equivalence)

Under A1–A2 the constrained minimization problem has a unique solution, and $u_h \in \Vh$ solves it if and only if

\[ \begin{aligned} (\Pi \A u_h, q_h)_{L^2(\Th)} &= (\Pi f, q_h)_{L^2(\Th)} && \forall\, q_h \in \IQ_h, \\ j_h(u_h, v_\IT) &= 0 && \forall\, v_\IT \in \IT. \end{aligned} \]

The first equation is by definition of $\Pi$ ($L^2$-orthogonal projection).

For the second: $V_h^f = u_p + \IT$

\[ \vert u_h + t v_\IT \vert_{j,h}^2 = \vert u_h \vert_{j,h}^2 + t j_h(u_h, v_\IT) + t^2 \vert v_\IT \vert_{j,h}^2 \] By assumption: $u_h \mapsto \vert u_h \vert_{j,h}^2$ is strictly convex and coercive on $\IT$, so stationarity is necessary and sufficient for optimality, so \[\frac{d}{dt}\vert u_h + t v_\IT \vert_{j,h}^2 \vert_{t = 0} = j_h(u_h, v_\IT) \overset{!}{=} 0. \]

Analysis

Stability

Assumption (local isomorphism, replaces A1)

There are $c_{\mathrm{loc}}, C_{\mathrm{loc}}, C_{\mathrm{tr}} > 0$, independent of $h$, with

\[ c_{\mathrm{loc}} \Vert v \Vert_{\star,K} \le \Vert \mathcal{R}_K v \Vert_{L^2(K)} \le C_{\mathrm{loc}} \Vert v \Vert_{\star,K} \quad \forall v \in \IL(K), \ K \in \Th, \qquad \vert v_\IL \vert_{j,h} \le C_{\mathrm{tr}} \Vert v_\IL \Vert_{\star,h}, \]

where $\mathcal{R}_K v \coloneqq \Pi_K \A v : \IL(K) \to \IQ(K)$.

Theorem (uniform inf-sup stability)

With $Z_h \coloneqq \IQ_h \times \IT$ and $B_h(v_h,(q_h,w_\IT)) \coloneqq (\Pi \A v_h, q_h)_{L^2(\Th)} + j_h(v_h,w_\IT)$,

\[ \sup_{0 \ne z_h \in Z_h} \frac{\vert B_h(v_h,z_h) \vert}{\Vert z_h \Vert_{Z,h}} \ge \bigl( C_{\mathrm{stab}} \bigr)^{-1} \Vert v_h \Vert_{\mathrm{ETLS},h} \qquad \forall v_h \in \Vh, \]

where $\Vert v_h \Vert^2_{\mathrm{ETLS},h} = \Vert \Pi \A v_\IL \Vert^2_{L^2(\Th)} + \vert v_\IT \vert^2_{j,h}$ is a norm on $\Vh$.

Analysis

Error estimator

We consider the elementwise estimator

\[ \eta^2_K \coloneqq \Vert f - \A u_h \Vert^2_{L^2(K)} + \sum_{F \in \Fh \cap \partial K} \Bigl( \Vert \dgjump{u_h} \Vert^2_{L^2(F)} + \Vert \dgjump{\nabla u_h \cdot \bm{n}} \Vert^2_{L^2(F)} \Bigr), \qquad \eta^2 \coloneqq \sum_{K \in \Th} \eta^2_K \]
  • Define two norms on the discrete space $\Vh$: \[ \Vert v_h \Vert^2_{\mathrm{ETLS},h} \coloneqq \widehat{\J}_h(v_h) = \Vert \Pi \A v_h \Vert^2_{L^2(\Th)} + \vert v_h \vert^2_{j,h}, \qquad \Vert v_h \Vert^2_{\mathrm{DGLS},h} \coloneqq \J_h(v_h) = \Vert \A v_h \Vert^2_{L^2(\Th)} + \vert v_h \vert^2_{j,h} \]
  • Since $\J_h(u_h) = \Vert u - u_h \Vert^2_{\mathrm{DGLS},h} = \eta^2$ for $u \in H^2(\Omega)$, the estimator is reliable and efficient with constant $1$ in the $\Vert \cdot \Vert_{\mathrm{DGLS},h}$ norm
  • In the $\Vert \cdot \Vert_{\mathrm{ETLS},h}$ norm reliability is automatic, since $\Vert u - u_h \Vert^2_{\mathrm{ETLS},h} \le \Vert \Pi \Vert^2 \eta^2$
  • Efficiency needs control of the projection defect \[ \Vert (\Id - \Pi) \A v_h \Vert_{L^2(\Th)} \le ??? \]
    • vanishes whenever $\A \Vh \subseteq \IQ_h$, e.g. for $\A = - \Delta$

Numerical results

Basic validation: The Laplace problem

We consider the Laplace equation with Dirichlet boundary conditions:

\[ - \Delta u = f \text{ in } \Omega, \qquad u = 0 \text{ on } \Gamma_{\text{D}} \]
  • Here $\A \Vh \subseteq \IQ_h$ for $\IQ(K) = \IP^{k-2}(K)$, so the analysis applies and the estimator is efficient
  • $\Omega = (0,1)^2$, $u_{\text{ex}} = e^x \sin y$, source $f = 0$, Dirichlet data from $u_{\text{ex}}$, $p = 2,\dots,5$
  • FOSLS as comparison: $\bm{\sigma} = \nabla u$ on the conforming pair $U_h = \IP^p(\Th) \cap H^1(\Omega)$ and $\Sigma_h \subset H(\div;\Omega)$ of order $p-1$: \[ \min_{(v, \bm{\tau}) \in U_h \times \Sigma_h} \Vert \div \bm{\tau} + f \Vert^2_{L^2(\Omega)} + \Vert \bm{\tau} - \nabla v \Vert^2_{L^2(\Omega)} + \alpha \Vert v - g \Vert^2_{L^2(\partial \Omega)} \]

Model problem

The Helmholtz equation

We consider the Helmholtz equation with mixed impedance and sound soft boundary conditions:

\[ - \Delta u - \omega^2 u = f \text{ in } \Omega, \qquad \nabla u \cdot \bm{n} - i \omega u = 0 \text{ on } \Gamma_{\text{R}}, \qquad u = 0 \text{ on } \Gamma_{\text{D}} \]
  • Analysis (local stability under $\omega h \lesssim 1$) similar to Stocker, Voulis (2026)
  • Adaptivity: incoming plane wave scattered by an L-shaped sound-soft obstacle cf. Bespalov et al. (2019)
    • $\Omega = [-1,1]^2 \setminus L$, $\ \Gamma_{\text{D}} = \partial L$, $\ \Gamma_{\text{R}} = \partial \Omega \setminus \Gamma_{\text{D}}$
    • $\omega=65$, $p = 7$
    • Dörfler marking with $\theta_{\text{ref}} = 0.25$
    • the estimator picks up the re-entrant corner singularities of $L$ without a priori information

Anisotropic Helmholtz

Nothing in the construction is tied to constant coefficients:

\[ - \div( \Am \nabla u ) - \omega^2 u = f \text{ in } \Omega, \qquad \Am \nabla u \cdot \bm{n} - i \omega u = 0 \text{ on } \partial \Omega, \]

with $\Am \in L^\infty(\Omega, \mathbb{R}^{d \times d})$ symmetric and uniformly positive definite a.e.

  • No plane-wave Trefftz basis is available here
    • embedded TDG computes $\IT(K) = \ker(\Pi_K \A)$ elementwise
  • dof reduction is unchanged
  • Example: $\Am$ twists by $90^\circ$ over $\vert \bm{x} \vert \le 0.35$ \[ \Am(\bm{x}) = R^T\begin{pmatrix}4&0\\0&1\end{pmatrix}R,\qquad R(x,y)=\begin{pmatrix}\cos\!\left(\frac{\pi}{2}e^{-(x^2+y^2)/0.35^2}\right)&-\sin\!\left(\frac{\pi}{2}e^{-(x^2+y^2)/0.35^2}\right)\\\sin\!\left(\frac{\pi}{2}e^{-(x^2+y^2)/0.35^2}\right)&\cos\!\left(\frac{\pi}{2}e^{-(x^2+y^2)/0.35^2}\right)\end{pmatrix}\]

Numerical results

Advection-reaction-diffusion in non-divergence form

For convex $\Omega$, a matrix field $\Am(x) \in L^\infty(\Omega,\mathbb{R}^{d \times d}_{\text{sym}})$, $\bm{b} \in L^\infty(\Omega,\mathbb{R}^d)$ and $c > 0$:

\[ \Am(x) : \hessian u + \bm{b} \cdot \nabla u - c u = f \text{ in } \Omega, \qquad u = 0 \text{ on } \partial \Omega \]
  • $\Am$ is not assumed differentiable — there is no divergence form and no standard weak formulation Lakkis, Mousavi (2021)
  • Assume that $\Am$ satisfies a Cordes condition Smears, Süli (2013): $\exists \gamma > 0$ such that $\vert \gamma \Am - \Idm \vert_F < 1$.
  • Test case: $\Omega = (0,1)^2$, $c = 2$, \[ \Am(\bm{x}) = \begin{pmatrix} 1 + \frac{x_1^2}{\vert \bm{x} \vert^2} & \frac{x_1 x_2}{\vert \bm{x} \vert^2} \\[2pt] \frac{x_1 x_2}{\vert \bm{x} \vert^2} & 1 + \frac{x_2^2}{\vert \bm{x} \vert^2} \end{pmatrix}, \qquad \bm{b}(\bm{x}) = \begin{pmatrix} x_1 x_2 \\ 1 \end{pmatrix} \] \[ u_{\text{ex}}(\bm{x}) = \vert \bm{x} \vert^{\alpha}, \qquad \alpha = 1.6 \]
  • Corner singularity limits uniform refinement

Conclusion

Embedded Trefftz least squares

Minimization over $V_h^f = \{ v_h \in V_h: \Pi(\A v_h - f) = 0 \} = u_p + \IT$

\[ \min_{v_h \in \Vh} \widehat{\J}_h(v_h) \ \text{ s.t. } \ \Pi(\A v_h - f) = 0 \qquad \Longleftrightarrow \qquad \min_{v_h \in u_p + \IT} \vert v_h \vert^2_{j,h} \]

1 Easily assembled

✓ usual DG integrals, small elementwise SVD

2 Standard spaces

✓ standard DG space $\IP^k(\Th)$, no conformity and no auxiliary variable

3 Conditioning

✗ $\mathcal{O}(h^{-4})$ inherited from the ambient DG space

  • Fewer dofs at the same accuracy, in particular for high $p$
  • Adaptivity: $\J_h$ is a reliable estimator, efficient under a resolution condition
  • Flexibility: variable and anisotropic $\Am$, non-divergence form, nonlinear $\A$, polytopal elements
